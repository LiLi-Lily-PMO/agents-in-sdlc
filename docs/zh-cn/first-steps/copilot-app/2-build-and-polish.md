使用一个详细的提示词构建 Space Quiz，在集成浏览器中验证行为，并用元素选择器优化视觉效果。

本课将：

- 在 `index.html` 中创建无依赖项的测验。
- 在集成浏览器中测试测验。
- 检查生成的代码。
- 在保持无障碍支持的前提下优化选中的元素。

## 构建测验

在 `space-quiz` 会话中发送以下提示词：

```plaintext
创建一个包含 10 道题的太空探索问答游戏，添加进度条、得分计数器和色彩鲜明的动画反馈（答对时为绿色，答错时红色抖动）。结束时显示带表情符号反馈的结果页面。内容在窄列中居中。只使用单个 index.html，不需要服务器或依赖项。采用精致的无衬线设计，正文为 14–16px，并遵循 prefers-color-scheme。在集成浏览器中打开。
```

智能体完成后，尝试回答几道题，并确认：

- 进度条向前推进。
- 得分更新。
- 答对时显示绿色状态。
- 答错时显示红色抖动动画。
- 最后一题结束后出现结果界面。

## 检查生成的代码

折叠左侧边栏和右侧浏览器面板，然后在展开的代码区域中查看 `index.html`。留意 HTML、CSS 和 JavaScript 如何在同一个文件中协作。完成后恢复两个面板。

## 使用元素选择器优化

1. 选择浏览器工具栏中的元素选择器。
2. 选择测验标题或答案区域。
3. 发送以下提示词：

   ```plaintext
   让选中的元素更有任务控制台显示屏的感觉。保持无障碍，并保留现有的浅色和深色主题。
   ```

4. 观察集成浏览器刷新，并验证更改。

## 可选优化

如果想继续尝试，可以让智能体：

- 添加淡雅的星空背景，并遵循 `prefers-reduced-motion`。
- 得分为 8 分或更高时，让结果界面更有庆祝氛围。
- 改善键盘焦点状态，然后在不使用鼠标的情况下验证测验。
